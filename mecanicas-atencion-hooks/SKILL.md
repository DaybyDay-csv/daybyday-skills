# Mecánicas de atención y hooks

Esta skill responde a una sola pregunta: ¿por qué un cerebro humano frena el scroll? Quien domina
los mecanismos inventa hooks infinitos; quien copia plantillas se queda seco en una semana.

## Cómo usarla

1. Antes de escribir un hook, decide la MECÁNICA, no la frase. Elige una (o combina dos) de las 18
   mecánicas maestras según las tres preguntas que el cerebro hace en 0.3s: ¿es importante/peligroso
   para mí?, ¿es nuevo?, ¿va sobre mí o mi tribu?
2. Construye el hook con la anatomía de 4 tiempos: frenar → orientar → crear tensión → prometer
   payoff. Y luego paga el payoff (hook-body match).
3. Para generar variantes, abre el swipe file por mecánica y cambia las palabras, no el mecanismo.
4. Para diagnosticar un hook que no funciona, usa la sección de fallos y ética (clickbait sin pago,
   fatiga, sobre-activación, falsa escasez).

## Regla núcleo

Frenar ≠ retener. La saliencia visual compra 0.3 segundos; el significado compra el resto. Un hook
es una promesa, y toda promesa es una deuda: si el cuerpo no la paga, el algoritmo te cobra con
distribución.
